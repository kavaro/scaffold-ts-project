# Scaffolf-ts-project

Is a git repository used to quickly scaffold a typescript project.

# Usage

- `clone` this repo from github
- Give your project a new name in the package.json
- Execute `bun run scaffold`, this resets the git history and 
  initializes a new `git`instance for your project 
- develop you code and when ready to push, commit your code
- `bun run release`:  this will test and build the project and push the repo to remote origin
